Welcome to the Adapdev blog. This is where product release notes, short
technical write-ups, and the occasional note on Australian small-business
software land first.

## What's here

- **Release notes** for the Adapdev Document Management System (ADMS).
- **Short essays** on building on-premises software in 2026 for a market
  that isn't well-served by subscription-only SaaS.
- **Practical pieces** — how to migrate a shoebox of client files into
  something searchable; how to think about backup when the data is yours;
  what the Privacy Act actually requires of a small firm.

If any of that is useful, the RSS feed is at [/blog/rss.xml](/blog/rss.xml).

## About the project

ADMS is a .NET 9 application. The server-side is a REST API with a SQLite or
SQL Server back end; the client is a WPF desktop app built on the Prism
framework. It integrates with Microsoft Office so documents can be saved to
the right client, matter or job from inside Word, Outlook, Excel and
PowerPoint.
